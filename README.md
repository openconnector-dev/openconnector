# Open Connector

Open Connector is an agent-first, self-hostable connector platform for AI agents.

The project source code is being prepared for public release and will be published here soon.

In the meantime, visit [openconnector.dev](https://openconnector.dev/) for product information and [docs.openconnector.dev](https://docs.openconnector.dev/) for documentation.
